In this tour we open each page of AI Ledger once, with our own data, and read the one figure that page leads with. There are eight stops of under two minutes each.

Before we start, AI Ledger must be running and its first ingest done: the navigation bar shows the time of the last ingest, not **Ingesting…**. If it is not running, follow [Install and first run](/ai-ledger/start/install/) first.

Every stop is a tab in the navigation bar at the top, except two: Judgments is a view of Activity, and the last stop has no tab. The tabs are in two groups, **Now** (Live, Limits) and **Review** (Activity, Cost, Context, Errors). The filters in the scope bar, under the navigation, start on the last 30 days, all projects and every agent; we leave them so.

## Activity: what got done

Select the **Activity** tab. Its heading counts commits and the prompts they came from, for example "214 commits from 1,032 prompts". The Sessions tile under the work chart counts sessions and active days.

Look at the **Needs attention** card below it. It lists error loops, sessions that reached 80% or more of their context window, tools that fail often and failed test runs. When there is nothing to list, it says "Nothing needs attention".

<ThemedImage dark={attention} light={attentionLight} alt="The Needs attention card on Activity, with demo data: error loops, sessions near the window, failing tools and failed test runs." />

More: [Activity](/ai-ledger/pages/activity/).

## Cost: what it cost

Select the **Cost** tab. Its heading gives the period's estimated cost, for example "$1,284.50 estimated cost", and its change against the 30 days before.

Read the plan gauge beside the heading. It shows the month's cost so far and the pace for the month: "on pace for ~$1,400". When AI Ledger knows our plan, a tick marks its monthly price and a badge compares the two: "7.0× plan". The cost is estimated at API list prices; **How measured** under the heading says how.

Scroll to **Project spend and change**. Each row is one project: its daily trend, its spend, and its change against the 30 days before.

More: [Cost](/ai-ledger/pages/cost/), and [How cost is estimated](/ai-ledger/concepts/cost-estimates/).

## Context: how full the context gets

Select the **Context** tab. Its heading says how much context a typical session starts with, for example "A typical session starts with 24,310 tokens of context, 12% of its window."

Read the **Tips** strip under it. Each tip shows only when a fixed rule fires; select one to open its evidence, its advice and the sessions that match. Under the tips, three tabs split the page: **Overhead and pressure**, **Growth and bloat** and **Cache health**.

<ThemedImage dark={tips} light={tipsLight} alt="The Tips strip on Context, with demo data: each tip that fired, as a short item." />

More: [Context](/ai-ledger/pages/context/).

## Errors: where the agents failed

Select the **Errors** tab. Its heading counts the failed tool calls and their share of all tool calls, and names the error type with the most of them.

Look at **Where to start**. It ranks the open fixes by the time each error type lost.

<ThemedImage dark={detail} light={detailLight} alt="Where to start on Errors, with demo data: the error types with a ready-made fix, and the fastest rising types." />

More: [Errors](/ai-ledger/pages/errors/).

## Limits: how much of the plan is used

Select the **Limits** tab. Its heading names the fullest plan limit window, for example "No limit runs out at the current pace. Fullest: Claude Code weekly, about 80% at reset."

If the heading says "No plan limits seen yet.", AI Ledger has no limit data yet. On a Mac it asks Anthropic for Claude Code's limits every 5 minutes; Codex records its limits in its own transcripts. If the Grok CLI is signed in with grok.com, the app asks xAI for Grok's limit every 5 minutes.

<ThemedImage dark={windows} light={windowsLight} alt="The open plan limit windows on Limits, with demo data: Claude Code and Codex, weekly and 5-hour, each with its pace and forecast." />

More: [Limits](/ai-ledger/pages/limits/), and [Context windows and plan limit windows](/ai-ledger/concepts/windows/).

## Judgments: how /insights judged the sessions

Select the **Activity** tab, then **Judgments** in the view switch above the heading. This view shows what Claude Code's `/insights` command wrote about our sessions: outcomes, friction and goals.

If we have never run `/insights`, the view says "No /insights data found." and tells us to run `/insights` in Claude Code, then Refresh. We can leave that for later.

<ThemedImage dark={outcomes} light={outcomesLight} alt="The Outcomes panel of Activity's Judgments view, with demo data: the share of analysed sessions in each outcome." />

More: [Judgments](/ai-ledger/pages/insights/).

## Live: what runs now

Select the **Live** tab. It lists the sessions that wrote in the last 10 minutes, grouped by who needs us first: **approval?**, **your turn**, **working**, **idle** and **ended**.

If it says "No session is active in this view.", open another terminal, start Claude Code, Codex or Grok in any project and send a prompt. The session appears on Live within a second, under **working**, and moves to **your turn** when the agent finishes.

<ThemedImage dark={rail} light={railLight} alt="The Active · last 10 min list on Live, with demo data: sessions grouped by who needs us first." />

More: [Live](/ai-ledger/pages/live/).

## Project: one project on one page

The last page is no tab. Select a project in the **Project** picker of the scope bar, under the navigation. The bar now ends with a **Brief →** link.

Select **Brief →**. The Project page gathers that project's activity, cost, top sessions, errors, context and share of the plan limits in two columns, each block linking to its page.

<ThemedImage dark={layout} light={layoutLight} alt="The Project page for atlas-api in two columns, with demo data: Activity, Cost and Context on the left, Errors, Plan limits and Sessions on the right." />

To go back to every project, select the ✕ button, "Clear project filter", in the scope bar.

More: [Project](/ai-ledger/pages/project/).

## What we have seen

We have read each page's lead figure once. To come back to them each week with a purpose, follow the [Weekly 15-minute review](/ai-ledger/improve/weekly-review/).

To move around faster, press **⌘K** on a Mac or **Ctrl+K** on Linux and type a page name: see the [command palette](/ai-ledger/everywhere/command-palette/).

To read more about a page while we are on it, select **Docs** in the navigation bar. It opens that page's documentation in a new tab: on Cost, the [Cost](/ai-ledger/pages/cost/) page of these docs. A **How measured** or **?** explanation can end with a **Learn more** link to the concept or glossary entry behind its figure.
