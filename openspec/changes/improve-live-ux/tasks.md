# Tasks

Privacy for every group: `data/` and the live store hold full transcript content. Never copy a real transcript line into `tests/`, `web/src/__fixtures__/`, `tools/demo/`, `design.md` or a commit, and never print one. Every test case and fixture is written by hand and is synthetic. To read real transcripts for evidence (task 1.4 and the Codex fields in 1.1), work on a copy of the store, as `AGENTS.md` describes, and record only the shape of what you find.

The group check, which every group ends with: `uv run ruff check && uv run python -m unittest discover -s tests && (cd web && npm run check)`. A group that changes `web/src` also commits `src/ai_ledger/web/`, and one that changes a payload also regenerates the fixtures with `uv run python -m unittest tests.test_web_fixtures`.

## 3. Stream

- [ ] 3.1 Show a shell call's description as its row text. In `ToolRow`, the text is `e.description` when the tool is a shell tool and it has one, else `e.summary`; the opened row shows the description and, apart, the command; the command is the row's title attribute. With Full text off the description is cut to `INPUT_CAP` in `live.py`'s `public`. Verify with `LivePage.test.tsx` and `test_live` cases: a call with a description shows it and, opened, shows both; one without shows the command; a 400-character description is cut with Full text off.
- [ ] 3.2 Lane folding and the last 5 rows. A lane starts folded when `done`; a running lane starts unfolded and shows its last 5 tool rows with a "Show all N rows" and "Show last 5" control; the user's fold and expansion choices are kept while the page is open, and a lane the user unfolded stays so when it finishes. Verify with `LivePage.test.tsx` cases for the scenarios: finished lane folded, running lane of twelve shows 5, show all shows 12, the user's unfold survives the lane finishing, an update for one lane leaves the others whole.
- [ ] 3.3 Lane header cost, model and errors: read cost and model from `lanes` in the session payload by lane id, count failed tool rows in the lane from the events held, leave out a figure that is unknown, and show errors only above zero. Verify with a `LivePage.test.tsx` case: a lane of 8 calls with 2 failed on a $0.05 haiku shows 8 tools, 2 errors, the model and $0.05; a lane with no cost shows none.
- [ ] 3.4 Make Follow lane-aware. With Follow on, scroll the row of the newest event (by timestamp) into view instead of the bottom of the box; a folded lane scrolls to its header; the scroll the page does itself does not turn Follow off (compare with the position it last set). Verify with a `LivePage.test.tsx` case with stubbed layout measurements: a new call in a running lane in the middle scrolls to that call and Follow stays on; a user scroll up still turns Follow off and shows Jump to latest.
- [ ] 3.5 Add `quiet` to tool events in `live.py`: true for `Read`, `Grep` and `Glob`, and for a shell call whose every simple command (through `categorize.commands`) is a read-only reader or searcher (`rg`, `grep`, `cat`, `sed`, `ls`, `find`, `head`, `tail`, `wc`, confirmed against Codex tool names found in real rollouts, shape only), with the list in one place. Add it to `LiveToolEvent` in `api.ts`. Verify with `test_live` cases: `Grep` is quiet; `git commit` is not; `rg TODO src` is; `rg TODO src && rm notes.md` is not.
- [ ] 3.6 Add the stream filters: the Errors count (agent panel and stream head) as a toggle button for failed tool rows, and Main thread only and Hide read-only toggles; filters combine, are page state off on every load, and survive a session switch; a lane with no matching row is hidden, one with matches shows them under its header; the stream says how many rows are hidden; figures and lane tool counts do not change. Verify with `LivePage.test.tsx` cases for every filter scenario, including the combined one and the reload.
- [ ] 3.7 Link the stream head to the session sheet on Activity (`sessionHref`, `appLink`), and date the times: `time()` includes the date when the event is not from the page clock's local day. Verify with `LivePage.test.tsx` cases: the head link points at the session's sheet; an event from yesterday shows its date, one from today does not.
