# Tasks

Privacy for every group: `data/` and the live store hold full transcript content. Never copy a real transcript line into `tests/`, `web/src/__fixtures__/`, `tools/demo/`, `design.md` or a commit, and never print one. Every test case and fixture is written by hand and is synthetic. To read real transcripts for evidence (task 1.4, the Codex fields in 1.1 and the commands in 3.5), work on a copy of the store, as `AGENTS.md` describes, and record only the shape of what you find.

The group check, which every group ends with: `uv run ruff check && uv run python -m unittest discover -s tests && (cd web && npm run check)`. A group that changes `web/src` also commits `src/ai_ledger/web/`, and one that changes a payload also regenerates the fixtures with `uv run python -m unittest tests.test_web_fixtures`.
