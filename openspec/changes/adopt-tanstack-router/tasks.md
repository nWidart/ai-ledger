# Tasks

Start after `adopt-tanstack` phase 4 merges (both changes rewrite the same test files, and group 4 here uses its `queries.ts`); rebase this change's branch on `main` first. Each group is one PR that passes `cd web && npm run check` and `uv run python -m unittest discover -s tests`, commits the build in `src/ai_ledger/web/`, and can be reverted alone. Versions, exact: `@tanstack/react-router` 1.170.46, `@tanstack/react-router-devtools` 1.167.3; check the registry when group 1 starts and record any newer version chosen in `design.md`.

Done ahead of that merge, on 2026-11-15, because they touch no file the other change touches: 1.1, 1.2 and 1.9. Everything else waits for it.

Model per task: **Haiku** for mechanical, well-defined edits; **Sonnet** for standard implementation and test work; **Fable** only where the decision or the debugging is hard.
