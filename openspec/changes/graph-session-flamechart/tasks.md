# Tasks

How to read a step:

- **Order.** "After X" means the step needs X merged into the change branch first. Steps of one **wave** run at the same time, at most two builders, and never edit the same file.
- **Risky.** A mistake in the step can pass its checks and still be wrong. The step says what its checks cannot see, and which step catches it.
- **Model.** The smallest model that can do the step reliably, with its effort: Sonnet for a well-defined or mechanical step, docs and images; Opus for standard building and any step with judgment. No step needs a larger model.
- **Check.** Python steps run `uv run ruff check` and `uv run pytest -n 2`. Web steps run, from `web/`: `npm run typecheck`, `npm run lint`, `npx vitest run --maxWorkers=2` (the step's own test files while it works, every test before it hands over), `npm run build`, `node scripts/check-bundle.mjs`. A fresh worktree first runs `cd web && npm ci && npm run build` (the Python tests need the build). The step names the tests that must exist and pass.
- **Browser.** Only steps 1.11 and 1.12 start a browser or the demo server, one after the other, in one slot, under the browser lock (the orchestrator adds its paragraph to those briefs). No other step starts a browser, Playwright or a server. Never `npx playwright install`.
- **Checkboxes.** A builder does not tick a box: steps run in parallel and the boxes would conflict. Step 1.13 ticks them all.
- **Files.** Change files with the Edit and Write tools only: no heredoc, `sed`, `perl -pi`, shell redirect or script that writes a repo file. Scratch scripts go in the builder's scratchpad.
- **Never edit** anything under `web/src/components/echart/`, nor `web/src/components/sheets/Timeline.tsx`, `web/src/components/sheets/session.ts` or `web/src/components/table/Table.tsx`. Import from them read-only. If a step seems to need an edit there, stop and report.
- **Never open the live store** (`~/Library/Application Support/ai-ledger/`). Measure on the demo store (`tools/demo/seed.py` copied to a scratch folder and run there), the fixtures or the tests' own stores.
- **Shared with `context-overhead-list`**, which is in flight: `web/src/api.ts`, `web/src/__fixtures__/`, `CHANGELOG.md`, `README.md`, `tools/demo/chartfit.mjs`, `tools/demo/record.mjs`, `web/scripts/check-bundle.mjs`. Keep each edit there to the fewest lines, and touch no line of that change's.
- **Tests** follow the "Tests" section of `AGENTS.md`: add an assertion to the test that already builds the fixture or the render; test a rule once, at the layer that owns it; export nothing only for a test. The plan aims at about 610 net test lines (design decision 12): a step that ends over its share says why in its handover.
- All design references are to `design.md` in this change. The new web files live in `web/src/components/sheets/spans/`.
