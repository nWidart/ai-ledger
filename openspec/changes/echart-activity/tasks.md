# Tasks

How to read a step:

- **Order.** "After X" means the step needs X merged first. "Parallel with X" means the two touch different files and can be built at the same time.
- **Risky.** A mistake in the step can pass its checks and still be wrong. The step says what the checks cannot see, and which step catches it.
- **Model.** The smallest model that can do the step reliably: Sonnet for a well-defined or mechanical step and for docs, Opus for standard building, Fable 5.2 only where the wrapper's contract changes.
- **Check.** Every step that touches `web/src` ends with `cd web && npm run check`. The step names the tests that must exist and pass.
- **Checkboxes.** A builder does not tick a box: steps run in parallel, and the boxes would conflict. Step 4.6 ticks them all.
- All design references are to `design.md` in this change. "The foundation" is `openspec/changes/archive/2026-11-21-echart-foundation/design.md`. Change files with the Edit and Write tools only.
- Group 1 is complete before any step of groups 2 and 3 starts.
