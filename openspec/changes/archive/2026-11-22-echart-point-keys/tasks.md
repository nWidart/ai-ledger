# Tasks

How to read a step:

- **Files.** What the step may change. A step changes no other file; if it must, it stops and says so.
- **Order.** "After X" means the step needs X merged first. "Parallel with X" means the two touch different files and can be built at the same time.
- **Browser.** The step runs a real browser or the demo server. Only one such step runs at a time on this machine, by the lock below.
- **Risky.** A mistake in the step can pass its checks and still be wrong. The step says what the checks cannot see, and which step catches it.
- **Model.** The smallest model that can do the step reliably: Sonnet for a well-defined or mechanical step and for docs; Opus for standard building. No step needs Fable 5.2: the contract and the rule are settled in `design.md`, on a draft that was measured. Give step 1.1 to Fable 5.2 only after a failed attempt.
- **Check.** Every step that touches `web/src` ends with `cd web && npm run check`. The step names the tests that must exist and pass. A fresh worktree needs `cd web && npm ci && npm run build` first.
- **Accept.** What must be true for the step to be done, beyond its checks.
- **Checkboxes.** A builder does not tick a box: steps run in parallel, and the boxes would conflict. Step 3.3 ticks them all.
- All design references are to `design.md` in this change. Read `AGENTS.md`, its "Tests" section included, before writing a test: extend the test that already builds the fixture, test a rule once at the layer that owns it, assert what a user reaches, and export nothing only for a test. Change files with the Edit and Write tools only.
- No payload changes, so no fixture is regenerated. A step that finds it must change a payload stops and says so.

**One browser at a time on this machine, by a lock.** The demo server drops connections under load. Every builder step that starts a browser or the demo server (`tools/demo/chartfit.mjs`, `firstscreen.mjs`, `typefit.mjs`, `record.mjs`, any Playwright script) must first take the lock with `mkdir /Users/nicolaswidart/.t3/ai-ledger-browser.lock` (atomic: it fails while another holds it), then write a one-line note with the Write tool to `/Users/nicolaswidart/.t3/ai-ledger-browser.lock/owner.txt` (thread title, step, start time). While the `mkdir` fails, the builder does its non-browser work or waits and tries again each minute; it never removes another's lock. It releases with `rm -r /Users/nicolaswidart/.t3/ai-ledger-browser.lock` as soon as its browser runs are done, and also when it stops on an error. A lock whose `owner.txt` is older than 3 hours: report it to the owner, do not remove it.

Never run `npx playwright install`: it hangs here. Use `CHROMIUM="$HOME/Library/Caches/ms-playwright/chromium_headless_shell-1223/chrome-headless-shell-mac-arm64/chrome-headless-shell"`. Stop a server by its process id. Use the demo store only, never the live store.
