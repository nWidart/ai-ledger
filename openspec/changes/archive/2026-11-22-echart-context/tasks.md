# Tasks

How to read a step:

- **Files.** What the step may change. A step changes no other file; if it must, it stops and says so. No step changes a shared chart file: `web/src/components/echart/EChart.tsx`, `option.ts`, `stack.ts`, `tokens.ts`, `testing.ts`, `zoomReset.tsx`, `realTesting.ts`, `echarts.ts`, or their tests. A step that finds it needs one stops and reports (decision 12).
- **Order.** "After X" means the step needs X merged first. "Parallel with X" means the two touch different files and can be built at the same time.
- **Waits for point-keys.** The step passes `view` and `pointKeys` to a wrapper that reads, so it starts only when the `echart-point-keys` change has merged to main and main is in this change's branch. It takes the prop's name, type and rules from the merged `EChart.tsx`, not from this plan. Steps 2.2, 2.3 and 2.4 wait. No other step does.
- **Browser.** The step runs a real browser. Only one such step runs at a time, under the owner's browser lock, with no other step running a build or a server: 4.1, then 4.2, 4.3, 4.4, 4.5, 4.6.
- **Risky.** A mistake in the step can pass its checks and still be wrong. The step says what the checks cannot see, and which step catches it.
- **Model.** The smallest model that can do the step reliably: Sonnet for a well-defined or mechanical step, docs and images; Opus for standard building. No step changes the wrapper's contract, so none needs Fable 5.2.
- **Check.** Every step that touches `web/src` ends with `cd web && npm run check`. The step names the tests that must exist and pass. A fresh worktree needs `cd web && npm ci` first.
- **Checkboxes.** A builder does not tick a box: steps run in parallel, and the boxes would conflict. Step 4.6 ticks them all.
- All design references are to `design.md` in this change. "The foundation", "the Activity design" and "the Errors design" are the three archived designs it names. Read `AGENTS.md`, its "Tests" section included, before writing a test. Change files with the Edit and Write tools only.
- The session map's steps (1.5, 2.5, 3.3, 4.4) touch no file another chart's step touches. They can be left out, or follow later, with nothing else waiting.
