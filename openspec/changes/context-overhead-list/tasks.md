# Tasks

How to read a step:

- **Order.** "After X" means the step needs X merged first. "Parallel with X" means the two touch different files and can be built at the same time.
- **Risky.** A mistake in the step can pass its checks and still be wrong. The step says what the checks cannot see, and which step catches it.
- **Model.** The smallest model that can do the step reliably: Sonnet for a well-defined or mechanical step and for docs, Opus for standard building. No step needs a larger model.
- **Check.** Web steps run, from `web/`: `npm run typecheck`, `npm run lint`, `npx vitest run --maxWorkers=2`, `npm run build`, `node scripts/check-bundle.mjs`. Python steps run `uv run ruff check` and `uv run pytest -n 2`. The step names the tests that must exist and pass.
- **Browser.** Only step 4.1 starts a browser. No other step starts a browser, Playwright or the demo server, and no step runs `npx playwright install`.
- **Checkboxes.** A builder does not tick a box: steps run in parallel, and the boxes would conflict. Step 4.4 ticks them all.
- All design references are to `design.md` in this change. Change files with the Edit and Write tools only. Fresh worktree: `uv sync`, then `cd web && npm ci && npm run build` before the Python tests.
- **Never edit** a file the `echart-context` change edits: `web/src/pages/context/ContextPage.tsx`, `ContextPage.test.tsx`, `sections.tsx`, the four Context charts and their tests, `web/src/theme.css`, `web/src/css.test.ts`, `web/src/components/echart/*`, `tools/demo/chartfit/*`, `tools/demo/record.mjs`, `tools/demo/firstscreen.mjs`, `site/src/assets/shots/README.md`, `site/src/content/docs/everywhere/keyboard-screen-reader.md`, `README.md`; and `web/scripts/check-bundle.mjs` and `site/src/content/docs/pages/context.mdx` only in steps 4.2 and 4.3, after that change merges. `CHANGELOG.md` is shared: add bullets only. If a step seems to need another of these files, stop and report.
- Tests follow the "Tests" section of `AGENTS.md`: add an assertion to the test that already builds the fixture or the render; test a rule once, at the layer that owns it; export nothing only for a test.
