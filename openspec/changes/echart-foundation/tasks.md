# Tasks

How to read a step:

- **Order.** "After X" means the step needs X merged first. "Parallel with X" means the two touch different files and can be built at the same time.
- **Risky.** A mistake in the step can pass its checks and still be wrong. The step says what the checks cannot see, and which later step catches it.
- **Model.** The smallest model that can do the step reliably: Sonnet for a well-defined change, Opus for standard building, Fable 5.2 where a wrong design choice spreads to every later chart.
- **Check.** Every step that touches `web/src` ends with `cd web && npm run check`. The step names the tests that must exist and pass.
- All design references are to `design.md` in this change. New files go in `web/src/components/echart/` unless a path says otherwise.
